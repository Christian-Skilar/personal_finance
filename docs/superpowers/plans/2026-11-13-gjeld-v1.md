> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** En installerbar norsk webapp (PWA) for Android der eieren registrerer lån og kreditt manuelt og ser nedbetalingsplan, plan vs. faktisk, hva-om, gjeldfri-plan og rentefradrag.

**Architecture:** Tre lag: `src/domain/` (rene, testede beregningsfunksjoner, ingen React/DB), `src/data/` (Dexie/IndexedDB + backup), `src/ui/` (React-skjermer). All visning av en nedbetalingsplan går gjennom `buildSchedule` i `src/domain/loan-schedule.ts`.

**Tech Stack:** Node 22 LTS, TypeScript, React 18, Vite, React Router (HashRouter), Dexie 4, vite-plugin-pwa, Vitest + jsdom + React Testing Library + fake-indexeddb.

**Spec:** `docs/superpowers/specs/2026-11-13-gjeld-v1-design.md`
**Skjermskisser:** https://claude.ai/artifact/U36JzyXBkdvSRmRm4SjFEh (6 skjermer: Oversikt, Lån-detalj, Månedlig oppdatering, Hva om, Gjeldfri-plan, Nytt lån). UI-oppgavene følger disse.

## Global Constraints

- All brukertekst på norsk bokmål. `<html lang="nb">`.
- Beløp lagres som heltall i øre (`type Ore = number`, alltid `Number.isInteger`). Aldri flyttall-kroner i lagring.
- Renter lagres som heltall i hundredels prosent (`5,20 %` = `520`). Månedsrente = `rate / 10000 / 12`.
- Måned = `"ÅÅÅÅ-MM"` (`YearMonth`), dato = `"ÅÅÅÅ-MM-DD"` (ISO-streng).
- Avrunding: til hele øre, halv opp (`Math.round` på positive tall). Siste termin tar resten slik at restgjeld blir nøyaktig 0.
- Formatering via `Intl` med locale `nb-NO`: `12 345,67 kr`, `5,20 %`, `13.11.2026`, `nov. 2048`. Intl bruker hardt mellomrom (U+00A0/U+202F); tester normaliserer med `const sp = (s: string) => s.replace(/[  ]/g, ' ')`.
- `src/domain/` importerer aldri fra `src/data/` eller `src/ui/`.
- Ingen nettverkskall med brukerdata. Ingen server.
- Farger/typografi fra skissene: bakgrunn `#F4F5F2`, tekst `#15201B`, dempet tekst `#5B6660`, primær `#0F5C4A`, mørk flate `#0F3D32`, varsel bakgrunn `#FCEBDD` / tekst `#9A3412`, feil `#B42318`, kantlinje `#E3E6E1`. Fonter: Inter (tekst), Space Grotesk (overskrifter). Trykkflater ≥ 44 px.
- Maks 600 måneder i alle simuleringer.
- Utviklingen er testdrevet: test først, se den feile, implementer, se den passere, commit.

## Review Focus

1. **Komma og mellomrom i beløp/rente** (`"2 450 000,50"`, `"5,2"`, `" 5.20 "`): skal tolkes riktig; `"abc"`, `""`, negative tall gir `null`. → tester i Task 2.
2. **Forfallsdag 29–31 i korte måneder** (dueDay 31 i februar): forfallsdato blir siste dag i måneden. → test i Task 3.
3. **Kreditt der innbetaling ≤ månedsrente**: skal gi `{ kind: 'never' }`, ikke uendelig løkke. → test i Task 5.
4. **Lån uten månedlige registreringer, eller registrering etter at lånet er ferdig/lukket**: status og prognose skal falle tilbake til planen og ikke krasje; restgjeld 0 gir "nedbetalt". → tester i Task 6.
5. **Backup-fil fra nyere skjemaversjon eller med ødelagt innhold**: avvises uten å røre eksisterende data. → tester i Task 9.

```ts
export type LoanKind = 'annuitet' | 'serie' | 'kreditt'
export interface RateChange { validFrom: IsoDate; nominalRate: RateBp }
export interface LoanTerms {
  kind: 'annuitet' | 'serie'
  startBalance: Ore; startDate: IsoDate; termMonths: number
  feePerTerm: Ore; dueDay: number; rates: RateChange[]   // minst én
}
export interface Installment {
  n: number; month: YearMonth; dueDate: IsoDate; rate: RateBp
  interest: Ore; principal: Ore; fee: Ore; payment: Ore  // payment = interest + principal + fee
  balance: Ore                                            // restgjeld etter terminen
}
export interface ScheduleOptions { fromBalance?: Ore; fromMonth?: YearMonth; extraPerMonth?: Ore }
export function annuityPayment(balance: Ore, rate: RateBp, terms: number): Ore  // ekskl. gebyr
export function rateAt(rates: RateChange[], date: IsoDate): RateBp
export function buildSchedule(terms: LoanTerms, opts?: ScheduleOptions): Installment[]
```

Regler (fra spec 3.4, presisert):
- Første termin er i måneden etter `toYearMonth(startDate)`. Med `fromMonth`: første termin er måneden etter `fromMonth`, startsaldo er `fromBalance`, og gjenværende terminer er `termMonths − monthsBetween(toYearMonth(startDate), fromMonth)`.
- Renten for en termin = `rateAt(rates, dueDate)`: siste endring med `validFrom ≤ dueDate`.
- Annuitet: terminbeløp beregnes ved start og på nytt når renten endres (med gjeldende restgjeld og gjenværende terminer av opprinnelig løpetid). Rente 0 → `balance / terms` avrundet.
- Serie: avdrag = `round(startsaldo / terminer)` fast.
- `extraPerMonth` legges til avdraget hver termin; terminbeløpet endres ikke; planen slutter når restgjeld er 0.
- Siste termin: avdrag = gjenværende restgjeld.

```ts
// credit.ts
export type CreditPayoff = { kind: 'paid'; months: number; payoffMonth: YearMonth; totalInterest: Ore } | { kind: 'never' }
export function creditPayoff(balance: Ore, rate: RateBp, monthlyPayment: Ore, firstMonth: YearMonth): CreditPayoff
// what-if.ts
export interface WhatIfResult { extra: Ore; payoffMonth: YearMonth; monthsSaved: number; interestSaved: Ore }
export function whatIf(terms: LoanTerms, base: ScheduleOptions, extras: Ore[]): WhatIfResult[]
// payoff-strategy.ts
export type Strategy = 'skred' | 'snoball'
export interface DebtForPlan { id: string; name: string; balance: Ore; rate: RateBp; minPayment: Ore }
export interface PayoffPlan { debtFreeMonth: YearMonth; months: number; totalInterest: Ore; order: { id: string; name: string; paidOffMonth: YearMonth }[] }
export function planPayoff(debts: DebtForPlan[], extraPerMonth: Ore, strategy: Strategy, firstMonth: YearMonth): PayoffPlan
```

Algoritme `creditPayoff`: hver måned `interest = round(balance * rate / 120000)`; `balance += interest − min(payment, balance + interest)`. Hvis `monthlyPayment ≤ round(balance * rate / 120000)` ved start → `never`. Måned 1 = `firstMonth`.

Algoritme `planPayoff` (måned 1 = `firstMonth`; maks 600):
```
prioritet: skred = høyest rente først (lik → lavest saldo); snoball = lavest saldo først (lik → høyest rente)
hver måned:
  pool = extraPerMonth
  for hver gjeld: hvis nedbetalt: pool += minPayment; ellers legg til rente, betal min(minPayment, saldo), pool += ubrukt del
  fordel pool i prioritert rekkefølge på gjeld med saldo > 0
  registrer paidOffMonth for gjeld som nå er 0
```
