# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Project

Personal finance project for tracking the owner's own finances. Early stage — no tech stack chosen yet. Update this file once the stack and structure are decided.

## Rules

- **Never commit real financial data or secrets.** Bank exports, statements, CSV/Excel files, `.env` files and keys belong in `data/` or `private/` (gitignored). Check `git status` before committing.
- Use synthetic/sample data in examples and tests.
- The owner writes in Norwegian; user-facing docs (README) may be in Norwegian.

## Git

- Remote: `origin` → https://github.com/Christian-Skilar/personal_finance.git
- Default branch: `main`
